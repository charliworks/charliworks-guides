# Glossary

> Last reviewed: 2026-11

| Term | Meaning here |
|---|---|
| **ADR** | Architecture Decision Record: a short note on one decision and why it was made. See [templates/adr.md](../project-management/templates/adr.md). |
| **DoD** | [Definition of Done](definition-of-done.md). |
| **MVP** | The smallest version that delivers the core value to real users. |
| **Spec** | A short document describing what to build and why, written before building. |
| **Slice** | A thin, end-to-end piece of a feature that can ship on its own. |
| **Skill** | A folder of instructions (`SKILL.md`) that an AI tool loads to do one kind of task well. |
| **Plugin** | An installable bundle for an AI tool. It can contain skills, commands, hooks, or MCP servers. |
| **MCP** | Model Context Protocol: how AI tools connect to external systems (GitHub, browsers, docs). |
| **Hook** | A command an AI tool runs automatically on certain events. Hooks run on your machine, so vet them. |
| **Stack profile** | Our preset list of AI tools for a project type. See [stack-profiles](../ai/setup/stack-profiles.md). |
| **Parking lot** | Where ideas wait until they're picked up. See [idea-parking-lot](../project-management/idea-parking-lot.md). |
