# charliworks-guides

The rulebook for **charliworks**. Read the relevant guide before you plan, design, or write code for any charliworks project.

It covers how we name things, commit, review, ship, design, use AI tools, and run the studio. If a rule here conflicts with a habit, the rule wins until someone changes it here through a PR.

## Start here

1. [Principles](00-start-here/principles.md): how we build and why
2. [Project kickoff checklist](00-start-here/project-kickoff.md): do this before the first line of code
3. [Definition of Done](00-start-here/definition-of-done.md): when something counts as finished
4. [Commit messages](workflow/commit-messages.md) and [branching](workflow/git-branching.md): you'll use these every day
